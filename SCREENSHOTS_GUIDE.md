# 📱 BuddyBloom App Screenshots Guide

This document provides a detailed breakdown of all the screenshots located in the `mobile/assets/app-screenshots` folder of the **BuddyBloom** app. You can use these descriptions to showcase the application's features and user workflows on your academy's website.

BuddyBloom is a full-stack educational academy management platform with three main user roles:
1. **Academy Administrator (Admin):** Manages revenue, billing, registrations, student/course analytics, and holidays.
2. **Teacher:** Manages class attendance, assigns homework, creates quizzes, and reviews student performance.
3. **Student / Parent:** Tracks attendance, submits leave requests, views fee summaries, takes quizzes, reviews results, and submits homework.

---

## 🎨 Theme Support
The application features a modern, responsive user interface with native support for both **Light Mode** and **Dark Mode** themes. The screenshots are categorized by their theme and function below.
